# TrueMark

Fact-grounded brand governance: check marketing copy against brand rules and approved facts before it ships.
Every finding cites the exact source passage, and a human decides what changes.

- `backend/`  FastAPI + ChromaDB + Gemini (see backend/README.md)
- `frontend/` Next.js UI (see frontend/README.md)

Run both locally: start the API on port 8000, then the web app on 3000.
